Magnitude Trial Report

Can Magnitude, an AI tool that drives the browser from plain-English steps, take over the fragile parts of our Shopify regression suite? We tried it on the product page of our live stores with every AI model we had access to.

Dates 30 Sep – 1 Oct 2026 Package magnitude-test 0.3.13 Stores Abc, Koh Runs 11
Verdict

Not ready for our suite. Do not adopt.

Magnitude read prices correctly, but it never completed a single click step. With every model available to us it clicked outside the browser window or wandered off to unrelated pages. The project behind it has also moved away from testing and ships dependencies with unfixed security issues.

What we tested

The same three checks as the earlier Midscene trial, on each store's default product page. The AI does the reading or clicking; a normal code check decides pass or fail, so the AI never grades its own work. Nothing went past Add to Cart.

MAG01

Read the price

AI reads the selling price from the screen; it must match the price our page object reads.

MAG02

Pick a different variant

AI selects another size, colour or pack; the page address must change to the new variant.

MAG03

Click Add to Cart

AI clicks the main Add to Cart button; the store's cart service must accept it (HTTP 200).

Findings

Reading works

On Abc the AI's price matched our page object twice, with two different models. A price check took 24–60 seconds.

Clicking does not

No click step finished. The models gave click positions outside the 1024 × 768 window, or left the product page and browsed other categories. On a live store that wandering is a risk, not just a failure.

Tool bug

Version 0.3.13 fails every second test in the same file with "browser has been closed". We worked around it by putting one test in each file.

Free AI limits stall it

Gemini's free plan allows 20 requests per model per day, and Magnitude spends many requests per step. Most runs were blocked by quota, overload or missing credit rather than by the store.

Risks in the tool itself

  • The original Magnitude project has moved on to other work. The test package was last released in February 2026 and its documentation site no longer loads.
  • Installing it adds 5 known vulnerabilities (3 high, in the image library it depends on), with no fix available.
  • The link we were given (github.com/ColeMurray/magnitude) is a personal copy of the project with no published package. We used the official package instead.
  • It sends usage data to its makers by default. We switched that off for the trial.

One useful finding for our suite

On Koh, both Midscene and Magnitude read the price as $23.59 and called $39.99 the crossed-out original price. Our page object reads $39.99. Two separate AIs agreeing suggests our Koh price check may be reading the wrong price. This needs a manual look.

Recommendation

  • Do not adopt Magnitude for the regression suite.
  • Stop the trial and remove it from the project, so the security warnings go with it.
  • Only if the team still wants a final answer: one run with a paid model it was designed for (OpenAI credit of about $5, or an Anthropic key). Given the risks above, we don't think it is worth the spend.
  • Check the Koh price selector.
